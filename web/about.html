About Morsebound

A free sound-first Morse code learning game for Web and Android.

Open Morsebound Learn Morse Code Privacy Terms

Mission

Morsebound is built around one simple goal: make Morse code recognition become a direct response to sound rather than a slow translation through a visual dot-and-dash chart.

How it teaches

Morsebound combines gradual character progression, useful character speed, Farnsworth-style spacing, adaptive review, active recall, retention checks, typed Real Copy, sending practice, and radio-style signal variation. The system gives extra attention to characters that are weak, slow, overdue, or commonly confused.

Signal Ops

The game presents training as restoration of a communications network. The visuals support motivation and tactical progression without permanently mapping a Morse character to an enemy, icon, or visual answer cue. Main recognition remains sound-first.

Accounts and offline use

Signing in is recommended so learning progress can synchronize between supported devices. Morsebound also preserves an explicit local/offline path for users who prefer not to create an account.

Privacy-first product choices

Morsebound does not include advertising or a dedicated analytics service in this release. Cloud accounts use Firebase Authentication and Cloud Firestore for synchronization. Users can delete their cloud account and synchronized data from inside the app or request deletion from the public deletion page.
