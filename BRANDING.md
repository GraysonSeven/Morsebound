# Morsebound

**Morsebound** is an adaptive, sound-first Morse code learning game.

- **Brand:** iCharles
- **Creator credit:** by iCharles — Charles Leanne S. Lioc
- **Project:** Project 2
- **Platforms:** Android + Web
- **Flutter package:** morsebound
- **Android application ID:** com.icharles.morsebound

Morsebound is built around auditory pattern recognition, adaptive repetition,
reaction-time measurement, retention scheduling, confusion targeting, and
progressive Morse mastery.
